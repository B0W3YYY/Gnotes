Estructura de carpetas

Frontend/
├── index.html              Inicio
├── css/styles.css          Estilos generales
├── js/
│   ├── auth.js             Sesión, roles y protección de páginas
│   ├── components.js       Navbar, footer y alertas compartidas
│   └── registro.js         Lógica del formulario de registro
└── pages/
    ├── registro.html
    ├── usuario/inicio.html
    ├── moderador/panel.html
    ├── admin/panel.html
    └── ui/                 Documentación de interfaz

Cómo crear una página nueva

  1. Copia una página existente de la misma carpeta.
  2. En <body> pon data-base con la ruta hacia Frontend/ (ej. "../../").
  3. Si es privada, agrega data-roles="usuario,admin" con los roles permitidos.
  4. Carga al final: Bootstrap, auth.js y components.js (en ese orden).
  5. Si debe salir en el menú, agrégala en MENU dentro de components.js.

Conexión con la API

La URL está en API_URL (js/auth.js): http://localhost:5001. El registro usa POST /usuarios. La API debe estar corriendo con npm run dev.
