Estructura de carpetas

Frontend/
├── server.js               Servidor del frontend (puerto 5002)
└── public/
    ├── index.html          Inicio
    ├── css/styles.css      Estilos generales
    ├── js/
    │   ├── config.js       Direcciones de la API
    │   ├── auth.js         Sesión, roles, protección de páginas y llamadas a la API
    │   ├── components.js   Navbar, footer, alertas y ventana de confirmación
    │   ├── guias-comun.js  Categorías, tarjeta de guía y utilidades
    │   └── (un .js por página)
    └── pages/
        ├── login, registro, recuperar, restablecer
        ├── usuario/        Mi panel, explorar, guía, crear guía, favoritos, perfil
        ├── moderador/      Panel de moderación
        ├── admin/          Panel de administración
        └── ui/             Documentación de interfaz

Cómo crear una página nueva

  1. Copia una página existente de la misma carpeta.
  2. En <body> pon data-base con la ruta hacia Frontend/ (ej. "../../").
  3. Si es privada, agrega data-roles="usuario,admin" con los roles permitidos.
  4. Carga al final: Bootstrap, config.js, auth.js y components.js (en ese orden).
  5. Si debe salir en el menú, agrégala en MENU dentro de components.js.

Conexión con la API

Las direcciones están en js/config.js. Para llamar a la API se usa llamarAPI(url, metodo, datos) de auth.js, que agrega el token de la sesión. La API corre con npm run dev en la carpeta API (puerto 5001) y el frontend con npm run dev en Frontend (puerto 5002).
