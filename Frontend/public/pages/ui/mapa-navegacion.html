Control de acceso (SCRUM-177)

  • El rol de cada usuario se guarda en la base de datos y solo un administrador puede cambiarlo.
  • Cada página privada indica qué roles pueden entrar; si no tienes sesión te manda a iniciar sesión y después te regresa.
  • La API revisa el token y el rol en cada acción, así que aunque alguien modifique la página no puede hacer lo que su rol no permite.
