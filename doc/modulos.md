| Comando o paquete | Función |
|---|---|
| `npm init -y` | Inicializar el proyecto |
| `express` | Crear el servidor y las rutas |
| `mongoose` | Conectar y trabajar con MongoDB |
| `dotenv` | Leer variables de configuración |
| `cors` | Controlar solicitudes desde otros orígenes |
| `nodemon` | Reiniciar el servidor al guardar cambios |
